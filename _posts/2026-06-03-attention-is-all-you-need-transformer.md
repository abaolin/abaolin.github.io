## 核心内容提炼

Transformer 抛弃了主导序列建模多年的循环（RNN/LSTM）和卷积结构，完全依靠注意力机制来建模输入与输出之间的全局依赖。它的核心洞见是：序列中任意两个位置之间的关系可以用一次注意力计算直接连接，无需逐步递推，因此训练高度可并行、长程依赖更易学习。凭借 Scaled Dot-Product Attention、多头注意力和正弦位置编码，Transformer 在 WMT 2014 英德翻译上取得 28.4 BLEU 的新纪录，且训练成本只是此前最佳模型的一小部分。这一架构后来成为 BERT、GPT 等几乎所有现代大模型的基石。

## 背景与问题：序列计算的根本瓶颈

在 Transformer 出现之前，机器翻译和语言建模等序列转换任务的主流方案是 RNN、LSTM 和 GRU 等循环神经网络，通常采用编码器-解码器结构，并辅以注意力机制连接两端。

这些循环模型有一个天然的限制：它们沿着序列的符号位置逐步展开计算，位置 t 的隐藏状态 `h_t` 依赖于前一个隐藏状态 `h_{t-1}` 和当前输入。这种内在的串行特性导致**无法在单个训练样本内部并行**——必须算完前一步才能算下一步。当序列变长时，这个问题尤为致命，因为显存约束又限制了跨样本的批处理规模。

以 ByteNet、ConvS2S 为代表的卷积方案试图通过并行计算缓解这一问题，但它们关联两个远距离位置所需的操作数会随距离增长（ConvS2S 为线性，ByteNet 为对数），仍然难以学习长程依赖。

Transformer 给出的答案是：彻底抛弃循环与卷积，仅依赖注意力机制，把任意两个位置之间的连接压缩为**常数级别的操作数**。

## Transformer 总体架构

Transformer 延续了经典的编码器-解码器框架，但把内部的循环层全部替换为注意力层和逐位置前馈网络。

**编码器**由 N=6 个相同的层堆叠而成，每层包含两个子层：
1. 多头自注意力机制；
2. 逐位置的全连接前馈网络。

每个子层都套有残差连接和层归一化，输出形式为 `LayerNorm(x + Sublayer(x))`。为了让残差连接顺利相加，模型中所有子层和嵌入层的输出维度统一为 `d_model = 512`。

**解码器**同样由 6 层堆叠，但在每层中额外插入第三个子层——对编码器输出执行多头注意力（即 encoder-decoder attention）。此外，解码器的自注意力子层引入了**掩码（masking）**机制：通过把非法连接的注意力得分置为 −∞，确保位置 i 的预测只能依赖位置 i 之前的已知输出，从而保持自回归特性。

整个模型是自回归的：解码时逐个生成符号，并把已生成的符号作为下一步的额外输入。

## Scaled Dot-Product Attention：注意力的核心算子

注意力的本质是把一个 query 和一组 key-value 对映射为输出，输出是 value 的加权和，权重由 query 与对应 key 的相似度决定。

Transformer 采用的是 **Scaled Dot-Product Attention**，公式为：

```
Attention(Q, K, V) = softmax(QKᵀ / √d_k) V
```

其中 query 和 key 的维度为 `d_k`，value 的维度为 `d_v`。计算流程是：query 与所有 key 做点积，除以 `√d_k`，经 softmax 得到权重，再对 value 加权求和。实践中所有 query 被打包成矩阵 Q，key、value 打包成 K、V，整个计算可以用高度优化的矩阵乘法一次完成。

**为什么要除以 √d_k？** 常见的注意力有加性注意力和点积注意力两种，点积注意力速度更快、更省空间。但当 `d_k` 较大时，点积结果的量级会随之增大——假设 q、k 各分量是均值为 0、方差为 1 的独立随机变量，它们的点积均值为 0、方差为 d_k。过大的点积会把 softmax 推向梯度极小的饱和区域。除以 `√d_k` 正是为了抵消这一效应，稳定梯度。

## 多头注意力：从多个子空间联合关注

如果只用一个注意力头，对 `d_model` 维的 query、key、value 直接做一次注意力，模型会因为加权平均而损失信息。Transformer 的做法是：把 query、key、value 用 h 组不同的、可学习的线性投影分别映射到 `d_k`、`d_k`、`d_v` 维，对每组投影并行执行注意力，得到 h 个 `d_v` 维输出，再拼接并经过一次线性投影得到最终结果。

```
MultiHead(Q, K, V) = Concat(head_1, ..., head_h) Wᴼ
headᵢ = Attention(Q Wᵢᵠ, K Wᵢᴷ, V Wᵢⱽ)
```

这样做的意义在于：**让模型同时从不同的表示子空间、不同的位置关注信息**。本文使用 h=8 个并行注意力头，每个头取 `d_k = d_v = d_model / h = 64`。由于每个头的维度被缩小，多头注意力的总计算量与单头全维注意力相当，却获得了更丰富的表达能力。

注意力在 Transformer 中有三种用法：
- **编码器-解码器注意力**：query 来自解码器上一层，key/value 来自编码器输出，使解码器每个位置都能关注输入序列的全部位置；
- **编码器自注意力**：query/key/value 都来自编码器上一层，每个位置可关注前一层所有位置；
- **解码器自注意力**：每个位置只能关注到自己及之前的位置（通过掩码实现），以保持自回归性。

## 位置编码与逐位置前馈网络

**逐位置前馈网络（FFN）**：在每个注意力子层之后，编码器和解码器的每一层都包含一个对每个位置独立且相同地应用的全连接前馈网络，由两个线性变换夹一个 ReLU 激活构成：

```
FFN(x) = max(0, x W_1 + b_1) W_2 + b_2
```

输入输出维度为 `d_model = 512`，中间层维度为 `d_ff = 2048`。它也可以理解为两个核大小为 1 的卷积。

**位置编码（Positional Encoding）**：由于模型既没有循环也没有卷积，它本身无法感知词序，因此必须显式注入位置信息。Transformer 在编码器和解码器底部的输入嵌入上加入位置编码，二者维度相同（均为 `d_model`）以便相加。本文采用不同频率的正弦和余弦函数：

```
PE(pos, 2i)   = sin(pos / 10000^(2i/d_model))
PE(pos, 2i+1) = cos(pos / 10000^(2i/d_model))
```

选择正弦函数的原因是：对任意固定偏移 k，`PE_{pos+k}` 都可以表示为 `PE_pos` 的线性函数，便于模型学习相对位置关系；同时正弦编码有望让模型**外推到比训练时更长的序列**。作者也实验了可学习的位置嵌入，发现两者效果几乎一致。

## 为什么选择自注意力

作者从三个维度对比了自注意力、循环和卷积层：

1. **每层的总计算复杂度**；
2. **可并行的计算量**（以所需的最少串行操作数衡量）；
3. **长程依赖的路径长度**——网络中任意两个位置之间信号传播路径越短，越容易学习长程依赖。

对比结果（n 为序列长度，d 为表示维度）：

| 层类型 | 每层复杂度 | 串行操作 | 最大路径长度 |
|---|---|---|---|
| 自注意力 | O(n²·d) | O(1) | O(1) |
| 循环 | O(n·d²) | O(n) | O(n) |
| 卷积 | O(k·n·d²) | O(1) | O(log_k(n)) |
| 受限自注意力 | O(r·n·d) | O(1) | O(n/r) |

关键结论是：自注意力以**常数级串行操作**连接所有位置，而循环层需要 O(n) 次串行操作；在 n 小于 d 时（这在主流词片/字节对表示中通常成立），自注意力比循环层更快。对于超长序列，还可以把自注意力限制在大小为 r 的邻域内，将路径长度增至 O(n/r)。

此外，自注意力还带来一个额外好处：**可解释性更强**。观察注意力分布会发现，不同的注意力头明显学会了不同的任务，许多头表现出与句子句法、语义结构相关的行为。

## 训练设置与实验结果

**数据与硬件**：英德任务使用 WMT 2014 英德数据集（约 450 万句对，字节对编码，共享词表约 3.7 万 token）；英法任务使用更大的 WMT 2014 英法数据集（3600 万句，词表约 3.2 万）。模型在单机 8 块 NVIDIA P100 GPU 上训练，base 模型训练 10 万步（约 12 小时），big 模型训练 30 万步（约 3.5 天）。

**优化器**：使用 Adam（β1=0.9, β2=0.98, ε=10⁻⁹），并采用带 warmup 的学习率调度——前 4000 步线性升温，之后按步数平方根的倒数衰减。

**正则化**：包括残差 Dropout（base 模型 P_drop=0.1）和值为 0.1 的标签平滑（label smoothing）。标签平滑虽然会损害困惑度，却能提升准确率和 BLEU。

**结果**：在 WMT 2014 英德翻译上，big 模型取得 **28.4 BLEU**，比此前最佳模型（含集成）高出 2.0 BLEU 以上，刷新了纪录；即便是 base 模型也超越了所有此前发表的模型和集成，而训练成本只是它们的一小部分。在英法翻译上，big 模型达到 **41.8 BLEU** 的单模型新最佳，训练成本不到此前最佳模型的 1/4。

从训练 FLOPs 来看，Transformer base 模型约 3.3×10¹⁸，big 模型约 2.3×10¹⁹，相比 GNMT、ConvS2S 的集成模型动辄 10²⁰~10²¹ 量级，效率优势极为明显。

## 影响与局限

**深远影响**：Transformer 的意义远超机器翻译本身。它证明了纯注意力架构不仅在质量上能超越循环与卷积模型，还在并行度和训练效率上有压倒性优势。作者还验证了它能很好地泛化到英语成分句法分析等其他任务（无论训练数据多寡）。在此之后，Transformer 成为整个深度学习领域的基础设施：BERT、GPT 系列、T5 等几乎所有现代大语言模型都建立在它之上，并进一步扩展到计算机视觉、语音、多模态等领域。

**局限与代价**：
- 自注意力的复杂度为 O(n²·d)，随序列长度呈平方增长，处理超长序列时计算和显存开销巨大，这也催生了后续大量稀疏/线性注意力的研究；
- 由于把所有位置的信息加权平均，单头注意力会降低有效分辨率，论文用多头注意力来缓解；
- 模型本身不感知词序，必须依赖位置编码显式注入位置信息；
- 论文中也提到对超长序列可采用受限邻域自注意力，但这只是初步设想，留待后续工作探索。

总体而言，《Attention Is All You Need》以一个简洁而优雅的架构，开启了序列建模乃至整个 AI 领域的新纪元。
